# 欢迎来到我的博客 👋

这是我的第一篇博客文章，记录搭建博客的过程。

## 为什么搭建博客

搭建个人博客是一个很好的习惯：

- **整理思路**：把学到的东西写下来，加深理解
- **分享知识**：帮助遇到同样问题的人
- **记录成长**：回头看自己的进步

## 技术栈

本博客使用以下技术搭建：

| 技术 | 用途 |
|------|------|
| Hexo | 静态站点生成器 |
| Next 主题 | 博客外观 |
| GitHub Pages | 免费托管 |

## 代码示例

作为技术博客，当然少不了代码：

```javascript
function sayHello() {
  console.log("Hello, World!");
  console.log("我的博客诞生了！🎉");
}

sayHello();
```
