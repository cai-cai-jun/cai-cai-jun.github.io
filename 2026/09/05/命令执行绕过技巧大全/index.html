Author: John Doe Date: September 5, 2026  10:00:00 Category: Web安全

一、cat 的替代品

当 cat 被过滤时，以下命令都可以代替 cat 读取文件内容：

命令 说明 特点
nl 带行号输出 最常用替代
tac 反向输出（cat 倒过来） 行顺序反转
rev 每行内容反转 字母顺序反转
more 分页查看 交互式
less 分页查看（增强版） 交互式
head 从头输出前 N 行 head -n 5 file
tail 从尾输出后 N 行 tail -n 5 file
sort 排序后输出 行顺序被打乱
grep 搜索并输出匹配行 grep . file 输出全部
uniq 去重后输出 不常用
od 八进制/十六进制显示 无 <?php 截断问题
base64 Base64 编码输出 无 <?php 截断问题

实战经验： 读取 PHP 文件时，cat 输出中的 <?php 会被服务器解释执行导致截断，此时用 base64 或 od 代替。

三、通配符绕过关键字

当 flag、php 等关键字被过滤时，用 shell 通配符匹配：

通配符 含义 示例
* 匹配任意长度 f* → flag.php, flag.txt
? 匹配单个字符 f??????? → flag.php（8个字符）

注意：

  • * 在 URL 中有时会被转义为 %2A
  • ? 在 URL 中是参数分隔符，需要用 %3F 编码
  • ? 通配符逐个字符匹配，更精准

案例一：web56 — 文件上传 + glob 绕过

源码：

字母、数字、几乎所有特殊字符都被过滤了，但 system($c) 是任意命令执行。

思路：利用 PHP 文件上传机制

  1. 发送 POST 请求上传一个文件，文件内容就是命令
  2. PHP 会在 /tmp/ 下创建临时文件 phpXXXXXX（9位）
  3. 用 Shell 的 .（source）命令执行这个临时文件

关键是 glob 匹配临时文件：

  • /???/ → 匹配 /tmp/（3位目录名）
  • ???????? → 匹配 8 个任意字符
  • [@-[] → 匹配大写字母 A-Z（ASCII 范围 0x40-0x5B）

为什么要 [@-[]？因为 /usr/bin/ 下的 BusyBox 命令都是小写字母，[@-[] 只匹配大写字母，跳过所有小写命令，才能匹配到 PHP 临时文件（随机字符中约 42% 概率最后一位是大写）。

两种思路对比

维度 web56（文件上传） flag in 36.php（算术展开）
绕过方式 PHP 文件上传 → 临时文件 → source 执行 Shell 算术展开 $((...)) 构造数字
关键允许字符 几乎全封 $ ( ) ! +
请求方式 POST（必须上传文件） GET
核心技巧 glob 通配符匹配 /tmp/phpXXXXXX $((...)) 算术展开 + %2b 绕过加号
原理本质 利用 PHP 自身机制（文件上传） 利用 Shell 自身机制（算术展开）

核心心法： 不要只想着”绕过过滤”，要思考”我还能用什么”。当字母和数字都被封了，Shell 本身的功能（算术展开、通配符、变量展开）可能就是你需要的新工具。
